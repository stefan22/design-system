# Spacing & Radius

Spacing follows Tailwind's default 0.25rem (4px) base scale. Border radius
is derived from a single `--radius` token in the shared theme
(`packages/tailwind-config/src/theme.css`), so changing one value re-tunes
every rounded corner in the system consistently:

```css
--radius: 0.625rem;
--radius-sm: calc(var(--radius) - 4px);
--radius-md: calc(var(--radius) - 2px);
--radius-lg: var(--radius);
--radius-xl: calc(var(--radius) + 4px);
```
