# Colors

All color tokens are defined once, as CSS variables, in
`packages/tailwind-config/src/theme.css`. They are expressed in **OKLCH**
for perceptually-uniform lightness across hues, and are re-mapped for dark
mode by simply swapping the variable values under the `.dark` class — no
component code changes between themes.

Tailwind's `@theme` block turns each `--color-*` variable into a utility
class, so e.g. `--color-primary` gives you `bg-primary`, `text-primary`,
`border-primary`, etc.

## Usage

```tsx
<div className="bg-primary text-primary-foreground">Primary surface</div>
<div className="bg-card text-card-foreground border">Card surface</div>
```

## Light / dark mode

Themes are toggled by adding/removing the `.dark` class on `<html>`, driven
by `next-themes` in `apps/web`. Every semantic token (`background`,
`foreground`, `card`, `primary`, ...) has both a light and dark value, so
components never branch on theme directly — they just use the semantic
class names.
