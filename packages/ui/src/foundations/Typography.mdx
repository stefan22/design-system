# Typography

The design system uses two font stacks defined in the shared theme:

- `--font-sans` — UI text (`font-sans`)
- `--font-mono` — code / tabular values (`font-mono`)

## Scale

| Class | Size | Typical use |
| --- | --- | --- |
| `text-xs` | 0.75rem | Captions, badges |
| `text-sm` | 0.875rem | Body small, form helper text |
| `text-base` | 1rem | Body |
| `text-lg` | 1.125rem | Emphasized body / small headings |
| `text-xl`–`text-4xl` | 1.25rem–2.25rem | Headings |

Weights follow Tailwind's default scale (`font-normal`, `font-medium`,
`font-semibold`, `font-bold`).
